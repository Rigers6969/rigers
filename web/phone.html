The phone can't open it?

1. RestartAfter switching phone mode on, close the black Wayne Factory window and open Wayne Factory again.
2. FirewallWindows Start → type "Allow an app through Windows Firewall" → Change settings → find Python → tick Private → OK. And in Wi-Fi settings set your home Wi-Fi to Private network.
3. Same Wi-FiWi-Fi on the phone, mobile data off, and the same Wi-Fi as the PC (not a "Guest" Wi-Fi).
4. Other addressIf the QR code still doesn't open, type the other addresses shown above (the one starting with 192.168 usually works).

From anywhere (school, work)

Use Tailscale: free, private, nothing is opened to the internet. Phone mode must be on.

1. On this PCInstall Tailscale from tailscale.com/download and sign in (Google account is fine).
2. On your phoneInstall the Tailscale app, sign in with the same account and switch it on.
3. Open itIn the Tailscale app find this PC's address (starts with 100.). Open http://100.x.x.x:5001 on the phone and type the PIN.

The PC has to be on, with Wayne Factory open. In Windows power settings set "Sleep" to Never while it's plugged in.
