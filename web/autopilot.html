    One-time setup for uploading

    1. Google keyIn Google Cloud Console make a project, turn on "YouTube Data API v3", create an OAuth "Desktop app" and download it. Save it as client_secret.json in the Wayne Factory folder.
    2. Connect each channelClick "Connect YouTube" next to a channel. Google's page opens: pick that channel's account and allow it. Done once per channel.
    3. Switch it onTurn the Autopilot on and choose the hour. Leave Wayne Factory open (Ollama running) and it works every night.
